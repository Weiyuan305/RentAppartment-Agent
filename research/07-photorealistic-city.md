# 已确认：实景三维城市

更新日期：2026-09-21。用户已明确要求实景城市效果。本决定取代最初“MapLibre 建筑挤出作为默认路线”的建议，后续不再把三维风格当作待确认问题。

## 1. 视觉目标

城市主视图呈现接近 Google Earth 的实景三维：真实街区、建筑屋顶与外立面纹理、道路及周边环境，支持平移、缩放、旋转和俯仰。初始视角采用适合观察街区的斜俯视，选择房源后移动至建筑附近。

主体验不能只用彩色建筑块、白模、示意楼高或普通卫星图片倾斜显示来验收。实景影像有采集时间，不能宣传为实时城市或保证反映当天环境。楼体细节、纹理清晰度和位置准确程度需通过实际数据验证。

## 2. 首选技术组合

**React / Next.js + CesiumJS + Google Photorealistic 3D Tiles + 自有房源图层 + PostGIS + Valhalla + AI SDK。**

- CesiumJS 负责三维场景、相机、选择标记与图层生命周期。
- Google Photorealistic 3D Tiles 提供真实世界的三维地理内容；Google 官方说明可由兼容渲染器加载。[数据概览](https://developers.google.com/maps/documentation/tile/3d-tiles-overview)
- Cesium 官方已有接入教程，使用 `Cesium3DTileset` 加载实景数据。[接入教程](https://cesium.com/learn/cesiumjs-learn/cesiumjs-photorealistic-3d-tiles/)
- 列表、聊天及房源位置仍由自己的业务数据驱动。步行时间、超市和区域资料按原架构单独计算，与实景渲染解耦。

接入渠道有 Google Map Tiles API 直连、通过 Cesium ion 访问两种候选。原型选择其中一条并按该渠道配置授权、token 与计量，不把不同教程的密钥和配额混用；具体商业渠道在核查账号条件后确定。本次未购买服务或创建付费账号。

CesiumJS 的开源许可与实景地图数据服务的授权、调用费用分别处理。先用供应商正式提供的服务验证，后续才决定是否增加其他已授权的摄影测量数据源。

## 4. 三栏找房在实景中如何工作

1. 进入城市：展示该城市已核查区域的斜俯视实景，首屏地图和左右面板同时可用。
2. 选择房源：使用自有房源坐标和已核验入口，镜头移动到合适的观察距离，展示价格标记和选中状态。镜头相对于目标定位，不直接冲到地面或穿进建筑。
3. 旋转视角：可以查看楼房周边环境；标记应有可读的遮挡策略，不能永远透过整座楼产生错误定位感。
4. 查看到校路线：叠加路由服务计算的步行线和目标校区；路线在三维场景中的贴合与可见性单独测试。贴图显示不能改变路线计算结果。
5. 自然语言筛选：更新自己的房源集合、校区和可达范围，实景底图保持稳定；每一条聊天 token 不重新创建三维 Viewer。
6. 查看详情：保留相机位置和房源选中，返回后恢复。

摄影测量城市可能是一片连续网格，不保证有独立的每栋建筑 ID。首版用自有房源点/价格标签完成准确选择；只有取得合法、准确的建筑边界数据后，再考虑整栋建筑轮廓高亮。不能承诺点击实景中任意楼房都能返回可租房源。

地图上的房源标记、POI 和路线是独立业务图层。数据来源和实景地图署名分别保留。Google Map Tiles 对机器解释、数据抽取和缓存有使用限制，不能从实景网格反推出自有房源库存、道路图或安全结论。[使用政策](https://developers.google.com/maps/documentation/tile/policies)

## 5. 第一轮原型的验收

| 验证点 | 通过条件 |
| --- | --- |
| 真实效果 | 在目标校区及房源街区看到具有真实纹理的三维建筑；记录实际截图和数据渠道 |
| 连续覆盖 | 环绕校区和样本房源观察，不出现影响找房的大片缺失；不能只看一个地标 |
| 镜头 | 缩放、旋转、俯仰、复位和选择房源后的飞行正常，没有明显穿模 |
| 定位 | 自有坐标对应正确建筑；同楼多个房型不会显示成不同位置 |
| 图层 | 价格标签、学校、路线和可达范围可见；标记不因地形高度明显漂浮/埋入 |
| 性能 | 在约定设备和网络上记录首屏、瓦片清晰时间、帧率、显存/内存；主动调整细节层级 |
| 恢复 | 切城市、打开详情返回、资源超时和 WebGL 上下文丢失有明确恢复行为 |
| 用量 | 记录一次城市浏览与切换的实际资源和计费用量，不先承诺固定低月费 |

先验伦敦一个明确校区，再对另外四个市场各选一处校区与样本房源验证。首城可以先用已标注的演示房源，但城市底图必须加载真实实景数据。

## 6. 对已有调研的影响

CesiumJS 升为首版主地图引擎；Cesium AI starter 是优先借鉴的交互模板。MapLibre/react-map-gl、OpenMapTiles、PMTiles、Martin 保留作历史对比或未来明确需要的轻量辅助地图研究，不加入首版实景主栈。

房源模型、五市场入口、价格/租期规则、AI 查询工具、真实步行筛选、安全资料的来源要求继续适用。开发阶段 A 的重点改为“实际纹理、具体覆盖、房源叠加和设备表现”，不再比较用户是否接受挤出建筑。
