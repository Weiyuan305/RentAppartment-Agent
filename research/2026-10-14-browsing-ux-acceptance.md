# 房源浏览体验：四项改进与验证

## 范围

1. 房源卡片默认显示图片、租金、账单、通勤时间和目的地；月支出、押金、一次性费用、条件匹配及规划入口进入「更多信息」。未知费用、估计通勤和演示数据说明保留。
2. 桌面左右面板支持拖动、方向键微调（Shift 加大步长）、Home/End、双击复原单侧，以及原有「恢复默认布局」。面板 280–480 px；窄桌面限制两侧总宽度，为地图保留空间。拖动使用 RAF 更新 CSS 变量，松手保存，不逐帧触发整个 React 工作区更新。
3. 筛选条件支持逐个移除及清空、一次撤销。撤销只恢复筛选和入住条件，不覆盖费用、目的地或其他规划；新条件操作后旧撤销失效。含「仅看收藏」。
4. 本机保存面板显隐、宽度和筛选栏收放；完整详情返回保存当前筛选、排序、展开卡片、列表锚点和三维相机位置/朝向。使用每城市一个会话快照及导航 token，普通分享链接不读取旧快照。详情的返回入口和浏览器返回均支持；聊天记录照常加载，但不会覆盖本次恢复的页面上下文。

布局偏好在 localStorage，详情返回快照在 sessionStorage，不上传账号；账号收藏及看房记录同步逻辑不变。浏览器禁用存储时退化为普通浏览。原有路由、地图、聊天、收藏、对比和规划入口保留。

## 本地验证（2026-10-14）

- TypeScript 检查通过，修改文件 ESLint 无错误；现有 img 警告仍在。
- 27 项测试通过：workspace-layout、rental-browse-ux、decision-experience、student-planner、student-agent。覆盖旧偏好迁移、宽度边界/复原、筛选隔离/撤销、无效/跨城市快照、返回地址校验及原有学生规划流程。
- 实际浏览器：1280×720 桌面，鼠标拖动及键盘调整，刷新记忆、单侧收放、专注模式、恢复默认。
- 组合筛选：租金 + 房型，单独移除租金后房型保留，撤销恢复；清空后可撤销。
- 完整详情返回和浏览器返回：展开卡片、滚动位置和过滤条件保留。三维数据加载稳定后，房源标记的屏幕坐标与返回前一致，异步路线和会话加载未将视角重置。
- 390×844、320×800 手机：中英文切换、筛选展开/折叠、移除/撤销，无横向溢出；手机不显示桌面宽度拖杆。
- 英文 280 px 列表、480 px 助手：无面板横向溢出。修正了深色模式下筛选标签的文字/背景对比度。
- Cloudflare 构建通过；构建守卫 secretLeaks=0、sqliteImports=0、hasD1=true。

以上为本地及构建证据；生产发布结果以完成后的公网验收为准。

## 公网验收补充

首次发布后，快速筛选触发了旧会话延迟返回覆盖新筛选的问题。会话初始化现记录请求开始时的 uiRevision，只有页面未发生新操作且没有详情恢复上下文时才应用旧状态；历史消息仍正常加载。补充了异步回归用例。
