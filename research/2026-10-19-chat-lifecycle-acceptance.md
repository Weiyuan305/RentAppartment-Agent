# AI 回复期间的页面生命周期验收（2026-10-19）

## 范围与复现

验收回复过程中刷新、切换城市、浏览器冻结后恢复，保持邮箱/Google 登录、游客、地图工具、主动停止和重试逻辑。

旧公网版本 `8715f93`：发送 Chapter House 到大学步行路线查询，在生成中刷新，恢复后仅有问题和“Reply stopped”，必须手动重试。请求中断被当成 Stop；客户端初始化只读取一次会话。

## 实现

- D1 在获取会话版本锁的同一次写入中保存问题与起点。重试复用已存问题，重复 ID 拒绝。
- Cloudflare SQLite Durable Object 承载每个会话的生成请求；页面连接断开后继续消费模型流并保存结果。没有更换模型、提高配额或自动重发工具调用。
- 普通 Worker `waitUntil` 的断线宽限只有 30 秒，不能覆盖已有 90 秒回复上限。Durable Object 的待完成 I/O 保持任务存活。参考：[Worker/DO 限制](https://developers.cloudflare.com/durable-objects/platform/limits/)、[DO 生命周期](https://developers.cloudflare.com/durable-objects/concepts/durable-object-lifecycle/)。
- 刷新、切回城市、visibilitychange、pageshow/bfcache、浏览器 resume 时同步城市会话。已完成的快照优先返回，避免长时间后台后误用旧计时器。
- 恢复是有截止时间的只读轮询；城市、消息 ID、页面修订号共同避免串话和覆盖用户新改的地图条件。租约到期或永久离线返回可重试状态。
- 主动 Stop 独立鉴权接口停止该用户的最新问题。客户端退出不会调用 Stop；停止后的迟到结果和旧版本不能覆盖新一轮。工具更新的地图状态途中落库。

## 自动检查与审查

- Agent 测试 30 项通过，包含持久化接收、取消响应消费者后继续完成、主动停止、重试去重、跨账号/城市隔离、旧版本写入保护、过期租约和恢复截止。
- 真实 D1 集成测试 4 项、workerd 模型恢复测试 1 项通过。
- TypeScript、改动文件 ESLint、diff whitespace、Cloudflare build guards 通过；构建产物无密钥、无 SQLite Node 原生依赖。
- 人工审查了前后台取消区别、恢复计时、Strict Mode effect 清理、其他标签页新任务、停止和完成竞态、版本锁与数据归属。
- 审查修正：前台恢复不复用已经结束的旧 request；已完成快照不再受旧超时影响；停止后继续保留已完成工具的记录；卸载恢复操作不能写入新城市。

## 隔离公网环境

与发布版本同一构建，独立 D1 和模拟模型；每个模型步骤延迟 20 秒，一轮两步约 40 秒。真实地图工具运行，模拟模型不计生产模型费用。

- 中文：生成中刷新 → 问题仍在 → 自动同步 → 完整回复 → busy=0，无错误提示。
- 中文：伦敦生成中切曼彻斯特 → 曼彻斯特无伦敦消息 → 切回伦敦取得完整回复。
- 英文：浏览器 CDP frozen/active → 恢复后完整回复，busy=0。
- 前三轮模型计数各为 2（查询一步、总结一步）；没有因为导航重发模型步骤。

手机尺寸采用浏览器 320/390px 验收，不等同于 iPhone/Android 真机。后台测试采用真实浏览器的冻结/恢复协议，不等同于手机系统杀进程。

## 边界

保证的是服务器已接收的问题。请求尚未到达服务器就关闭页面、服务器宕机或平台强制重启，不承诺一定生成完整答案；已存问题和工具状态仍可恢复，过期任务结束等待并提供重试。没有建立无限重试或后台无限任务。

最终补充验收：320px 英文 frozen/active 自动恢复完整结果；390px 中文主动 Stop 立即结束 busy，刷新后保留 stopped 和已完成工具状态。两种尺寸均无横向溢出；截图存于 Codex 本地验收目录。此次没有接入手机真机。
