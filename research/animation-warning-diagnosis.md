# 动画告警：来源与浏览器验收流程修正

## 结论

2026-10-15 排查的错误为：

```text
Uncaught (in promise) TypeError: Cannot use 'in' operator to search for 'animation' in undefined
```

该错误来自 Codex 内置浏览器在独立 SVG 文档中注入的脚本，不是 Campus Atlas 的动画代码。此前验收先打开 `/favicon.svg`，再进入网站，沿用同一标签页的累计控制台日志，误把准备阶段的错误归到了网站。此次修正验收流程和归因；网站功能与动效不需要修改，也没有通过全局错误拦截隐藏异常。

## 对照证据

验证对象是生产站点 `https://campus-atlas-demo.pages.dev`，应用提交为 `f26d9844eecf9c351b6a26616422ffe2847d131f`。

| 独立检查 | 观察结果 |
| --- | --- |
| 新标签页只打开 `/favicon.svg`，不进入应用 | 在 `2026-10-15T03:16:41.866Z` 出现上述错误 |
| 读取 SVG 响应 | HTTP 200、`image/svg+xml`、243 字节，仅有图形元素，无脚本 |
| 新标签页直接进入首页 | 页面、水合、实景地图与聊天输入就绪后，error/warn 日志为空 |
| 首页打开/关闭 Chapter House 详情、展开/收起地图图层、进入/退出专注地图 | 交互完成，error/warn 日志仍为空 |
| 新标签页先进入 `/login`，再禁用浏览器缓存并进入首页 | 登录页与首页均无 error/warn；实景地图已显示，聊天输入可用，无需刷新 |

调试器读取到的浏览器匿名预加载脚本位于独立执行上下文，包含动画事件前缀探测：先取 `document.createElement('div').style`，再以 `in` 检查 `animation` 等属性。独立 SVG 文档不是 HTML 文档，该方式创建的节点没有 HTML 元素的 `style`，因此右操作数为 `undefined`。这一调用链与 SVG 单独复现、真实 HTML 页无错误的对照结果一致。未把浏览器注入脚本或用户会话内容复制进仓库。

## 后续验收流程

1. 每次验收新建标签页，直接打开待测 HTML 页面；不使用 SVG、图片或其他非 HTML 资源准备调试会话。
2. 需要提前连接调试器时，先打开真实 HTML 入口（例如 `/login`），记录该阶段日志和时间，再导航到目标页。首次加载检查可在该标签页临时禁用缓存，结束后恢复。
3. 浏览器日志可能跨导航累计。记录当前 URL、日志时间及执行上下文，不能把同标签页全部历史错误都归到当前页面。
4. 复测详情图片展开/收起、图层开关、专注地图切换；等待过渡结束后检查最终 UI 状态，并读取本轮 error/warn。保留现有动画及减少动态效果偏好支持。
5. 脚本请求失败仍需独立排查。发布后运行 `cd app && npm run verify:assets`，检查 HTML 和 JS/CSS 一致性；此动画误报不推翻已修复的发布资源版本错配问题，详见 [脚本加载排查](./script-loading-reliability.md)。

## 验证边界

本次没有修改或修复 Codex 内置浏览器的注入代码。已确认的是网站正常访问及上述交互没有这条错误，修正后的验收流程不再制造该误报；这不代表在其他浏览器、任意网络状态或所有交互组合下永远没有异常。
